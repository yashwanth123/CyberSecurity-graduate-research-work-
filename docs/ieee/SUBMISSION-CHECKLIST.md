# IEEE Submission Checklist — ICSCI 2026

Complete every item before uploading to EDAS.

## Content

- [ ] Title ≤ 15 words, no abbreviations in title unless defined
- [ ] Abstract ≤ 250 words (current draft ~220)
- [ ] 5–7 IEEE keywords
- [ ] All acronyms defined at first use (IACS, SL-T, SL-A, OT, MES, PLC, DMZ)
- [ ] Contributions numbered in Introduction
- [ ] Limitations stated honestly in Discussion
- [ ] Results match `case-study-statistics.json`
- [ ] No fabricated citations — every `\cite{}` exists in `references.bib`
- [ ] Repository URL in Conclusion/Data availability

## IEEE format

- [ ] `IEEEtran` conference two-column template
- [ ] Page count within CFP limit (verify 6 pages on ICSCI site)
- [ ] Figures ≥ 150 dpi, readable in B&W
- [ ] Table I (maturity) included
- [ ] References in IEEE style (not APA)
- [ ] PDF fonts embedded (no Type 3 fonts if possible)
- [ ] Anonymization: **not required** for ICSCI (single-blind — check CFP)

## Authorship

- [ ] Author name and email correct
- [ ] Affiliation: Independent Researcher OR your company/university
- [ ] ORCID added (recommended)
- [ ] Corresponding author email active for EDAS notifications

## Ethics & integrity

- [ ] Case study anonymized (no plant name, IPs, geolocation)
- [ ] You can explain every claim if reviewer asks
- [ ] Plagiarism check run (Turnitin / iThenticate / Similarity check)
- [ ] Paper not submitted elsewhere simultaneously
- [ ] You read the full PDF start to finish

## Submission (EDAS)

- [ ] Account created at https://edas.info
- [ ] Workshop ICSCI 2026 selected
- [ ] PDF uploads without error
- [ ] Abstract text pasted matches PDF abstract
- [ ] Keywords entered
- [ ] Submitted before **16 August 2026** (Anywhere on Earth)

## After submit

- [ ] Save EDAS submission ID screenshot
- [ ] Calendar reminder: notification **13 September 2026**
- [ ] Calendar reminder: camera-ready **20 September 2026**
- [ ] Prepare 15-min slides if accepted

## Optional (increases acceptance odds)

- [ ] Fig. 1: architecture diagram
- [ ] Fig. 2: maturity bar chart
- [ ] Ask one MSCS colleague or OT practitioner to read §Evaluation
- [ ] Zenodo DOI for code — cite in footnote
